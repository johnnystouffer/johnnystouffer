You don't need all of Vim. You need these.

| Keys | Does |
| :--- | :--- |
| `ciw` | change word |
| `dt)` | delete until `)` |
| `%` | jump to matching bracket |
| `.` | repeat last change |
| `*` | search word under cursor |

## The trick

Learn *one* per day. Use it 20 times. Move on.
