I used to grind for days. Now I have a timer.

## The rule

> Stuck for **two hours**? Write it up and ask.

Writing it up solves it a third of the time. The other two thirds, someone answers in five minutes.

- [x] Set the timer
- [x] Write the question as if posting to a stranger
- [ ] Actually stop at two hours
